# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good intent, keep discussion on the work, and don't harass anyone, in any
project space (issues, pull requests, discussions) or when representing the project elsewhere.

## Reporting

Report unacceptable behaviour privately to the maintainers through a
[private security advisory](https://github.com/Rufics/fpv-radio-map/security/advisories/new) marked "Code of conduct",
or by contacting a maintainer directly. Reports are handled confidentially.

Maintainers may remove comments, commits, issues and other contributions that break this code, and may ban
contributors temporarily or permanently, following the enforcement guidelines of the Contributor Covenant.
